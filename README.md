#### Hobby project: Orchard

[Orchard](https://github.com/zainnobody/orchard) adds drivers, fixes and a Mac-like desktop to Linux on Apple silicon Macs.

- [apple-silicon-linux-kit](https://github.com/zainnobody/apple-silicon-linux-kit): the guide, kernel and Mesa patches, and install scripts you can undo. GPU acceleration and Touch ID.
- [apple-silicon-linux-desktop](https://github.com/zainnobody/apple-silicon-linux-desktop): `agx`, one installer for Ubuntu, Debian, Kali, Fedora and Arch.
- [apple-silicon-neural-engine](https://github.com/zainnobody/apple-silicon-neural-engine): Neural Engine research. Llama 3.1 8B already runs on the GPU at 22.7 tokens/s.

#### From my master's

- [Heart disease analysis](https://github.com/halliekinsey/heart_disease): Cleveland, Hungarian, Swiss and VA patient data merged into one set and modeled. With [Hallie Kinsey](https://github.com/halliekinsey).
